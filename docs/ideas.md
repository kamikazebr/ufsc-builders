# Where to find something worth building

Three doors. They answer different questions, which is why you want all three.

## What is about to become a standard

**[eips.ethereum.org](https://eips.ethereum.org)** — 611 ERCs is too many to
browse. The sharp filter is **Last Call**: the 14-day final review window before
a proposal goes Final.

<https://eips.ethereum.org/all#last-call>

That page is the short list of things that are about to be real and are not
widely implemented yet. There is an RSS feed. Subscribe to it.

## What people are still arguing about

**[ethereum-magicians.org](https://ethereum-magicians.org)** — where standards
get fought over before they are written.

An open thread with no agreement is a problem nobody has solved. That is a better
starting point for a hackathon than a solved problem with nine implementations.

## What has already been built

**[speedrunethereum.com/builds](https://speedrunethereum.com/builds)** — public,
no login. Filter by category: DeFi, Gaming, NFTs, Social, DAOs & Governance, Dev
Tooling, Identity & Reputation, RWA & Supply Chain, AI Agents, Prediction Markets.

Use it twice: to avoid rebuilding something that exists, and to see the *shape* of
a project that fits in a weekend. Most of them are smaller than you expect.

## And to actually get your hands in

**[speedrunethereum.com](https://speedrunethereum.com)** — BuidlGuidl's challenge
series. Challenge 0 is an NFT, and it is the same ground we covered here, done
properly with a frontend. If you want one thing to do before the hackathon, do
that one.

## Stuck on the idea itself

Ideas are the bottleneck more often than code — especially if you are not the one
writing the contracts.

The [BMAD](https://github.com/bmad-code-org/BMAD-METHOD) **brainstorming**
workflow runs a structured session with you: divergent techniques first,
convergent second, and it makes you name the user before the feature.

```
/bmad:core:workflows:brainstorming
```

Use that one workflow. Ignore the rest of the framework this weekend — PRDs,
architecture docs and epics are the right tools for a quarter, not for 48 hours.
